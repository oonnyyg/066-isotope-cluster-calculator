# 分子式同位素峰簇计算器

仅使用 Python 标准库（Python ≥ 3.12），依据离线元素同位素丰度表，计算一个或多个
分子式在**整数总质量数**上的同位素概率分布，并给出概率加权的平均精确质量与 `m/z`。

## 运行

```bash
python -m isotopes examples/input.json --out out
```

全部输入先在内存中校验、计算成功后才会写盘；任一非法输入都会向标准错误打印
“分子/元素 + 位置”信息，进程以非零码退出，且不会生成成功报告。

## 输入格式

输入为 UTF-8 JSON（允许带 BOM）：

```json
{
  "charge": 1,
  "formulas": [
    {"name": "water", "formula": "H2O"},
    {"name": "calcium_hydroxide", "formula": "Ca(OH)2"}
  ],
  "elements": {
    "H": [
      {"mass_number": 1, "exact_mass": 1.00782503223, "abundance": 0.999885},
      {"mass_number": 2, "exact_mass": 2.01410177812, "abundance": 0.000115}
    ]
  }
}
```

- `charge`：正整数电荷数。
- `formulas`：单个字符串，或 `{name, formula}` 对象数组（`name` 可省略，默认
  `molecule_1` 起）。
- `elements`：元素符号到同位素列表的映射。每个同位素含：
  - `mass_number`：正整数质量数，同一元素内必须唯一；
  - `exact_mass`：有限、正的精确质量，单位 u；
  - `abundance`：有限非负丰度；同一元素丰度和与 1 的差不得超过 `1e-9`，
    计算前按该和归一化。

## 分子式语法

- 元素符号为大写字母开头、可跟若干小写字母（`H`、`Ca`）。
- 下标为正整数，省略下标视为 1；下标 `0` 非法。
- 支持任意层级嵌套括号，括号后可带下标：`Ca(OH)2`、`((CH3)2CH)2`。
- 分子式与括号内容均不能为空；括号必须闭合；不支持小数系数或 `+`/`-` 离子符号。
- 未在元素表中声明的符号按“未知元素”报错，错误信息给出 1 基字符位置。

解析结果是合并后的 `{元素: 计数}`，例如 `Ca(OH)2` → `Ca:1, O:2, H:2`。

## 合并算法

假设同一分子中各原子的同位素选择相互独立：

1. 初始分布只有一个峰：质量数 0、概率 1、精确质量加权和 0。
2. 逐个原子做卷积。对每个同位素 `(M, m, p)`，把当前每个峰平移为
   质量数 `+M`、概率 `×p`、精确质量加权和 `×p + m×(原概率×p)`。
3. 卷积结果中**总质量数相同的组合合并**：概率相加，精确质量加权和相加。
4. 每个质量数峰的平均精确质量为“加权和 / 该峰概率”，即对落入同一整数质量数的
   所有同位素组合按概率取均值；不按精确质量近似分箱，也不裁剪低丰度峰。
5. `m/z = 平均精确质量 / charge`，忽略电子质量与加合离子。

只输出概率严格大于 0 的峰，按总质量数递增。

## 输出

- `out/summary.json`：`charge`、分子数量及每个分子的原始分子式、合并元素计数、
  峰数、`total_probability`、`mean_molecular_mass`（按峰概率加权的平均分子质量）
  和完整峰列表（`mass_number`、`probability`、`mean_exact_mass`、`mz`）。
- `out/<name>_z<charge>.csv`：每个分子的逐峰表
  `mass_number,probability,mean_exact_mass_u,mz`。
